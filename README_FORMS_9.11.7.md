# TSERTOS CRM V9.11.7 — Μόνιμη επαναχρησιμοποίηση προτύπων

- Το επιλεγμένο πρότυπο θυμάται ανάμεσα σε ανοίγματα της εφαρμογής.
- Νέο κουμπί «✓ Χρήση» για ήδη αποθηκευμένα πρότυπα.
- Το «＋ Νέο PDF» χρησιμοποιείται μόνο για πραγματικά νέα πρότυπα.
- Αν επιλεγεί ξανά το ίδιο ακριβώς PDF, αναγνωρίζεται με σταθερό byte fingerprint και χρησιμοποιείται το ήδη αποθηκευμένο πρότυπο χωρίς νέα αντιστοίχιση.
- Οι αντιστοιχίσεις, θέσεις και μεγέθη γραμματοσειράς παραμένουν αποθηκευμένα στο IndexedDB.
