# TSERTOS CRM V9.11.10 — Persistent Mapping Profiles

- Οι αντιστοιχίσεις αποθηκεύονται σε ξεχωριστό IndexedDB store από τα PDF.
- Η διαγραφή ενός PDF από τη βιβλιοθήκη δεν διαγράφει την αντιστοίχισή του.
- Αν ξαναφορτωθεί το ίδιο ακριβώς PDF, η αντιστοίχιση επανέρχεται αυτόματα.
- Οι υπάρχουσες αντιστοιχίσεις παλαιότερων εκδόσεων μεταφέρονται αυτόματα στο νέο store όταν ανοίξει η βιβλιοθήκη.
- Σε PDF χωρίς αντιστοίχιση εμφανίζεται «🔗 Έτοιμο πρότυπο» για χειροκίνητη σύνδεση με αποθηκευμένη αντιστοίχιση.
