# TSERTOS Insurance CRM — PWA OFFLINE V9.12.25

Η εφαρμογή εγκαθίσταται από το Safari χωρίς Xcode και χωρίς καλώδιο. Μετά την πρώτη φόρτωση λειτουργεί χωρίς internet και αποθηκεύει τις εγγραφές τοπικά στο iPhone μέσω IndexedDB.

## Αποδείξεις προς είσπραξη

1. Άνοιξε την εφαρμογή και πάτησε **Αποδείξεις**.
2. Πάτησε **Εισαγωγή Excel** και επίλεξε το αρχείο `.xlsx` με τις ανείσπρακτες αποδείξεις.
3. Η εφαρμογή δημιουργεί αυτόματα μία καρτέλα για κάθε μήνα από την **Έναρξη Οφειλής** και εμφανίζει το πλήθος των αποδείξεων του μήνα.
4. Η καρτέλα **Όλες** εμφανίζει όλες τις αποδείξεις από την παλαιότερη προς τη νεότερη ημερομηνία έναρξης οφειλής.
5. Χρησιμοποίησε την αναζήτηση ονοματεπωνύμου για να εμφανιστεί αμέσως η απόδειξη που θέλεις.
6. Πάτησε πάνω σε μια απόδειξη για να αντιγραφούν σε δύο γραμμές ο κωδικός πληρωμής RF και το τελικό ποσό.
7. Οι αποδείξεις αποθηκεύονται τοπικά και περιλαμβάνονται στο JSON backup.

## Δημοσίευση στο GitHub Pages

1. Συνδέσου στο GitHub και δημιούργησε νέο repository, π.χ. `tsertos-crm`.
2. Κράτησέ το **Private** μόνο αν ο λογαριασμός σου επιτρέπει GitHub Pages από private repository. Διαφορετικά μπορεί να είναι Public: το project δεν περιέχει προσωπικά δεδομένα πελατών.
3. Πάτησε **Add file → Upload files** και ανέβασε όλα τα αρχεία αυτού του φακέλου, όχι τον ίδιο τον εξωτερικό φάκελο.
4. Πάτησε **Commit changes**.
5. Πήγαινε **Settings → Pages**.
6. Στο **Build and deployment**, επίλεξε **Deploy from a branch**.
7. Επίλεξε branch **main**, φάκελο **/(root)** και πάτησε **Save**.
8. Περίμενε λίγα λεπτά. Η διεύθυνση θα είναι συνήθως `https://ΟΝΟΜΑ-ΧΡΗΣΤΗ.github.io/tsertos-crm/`.

## Ανάκτηση των παλιών δεδομένων

1. Με internet, άνοιξε στο Safari τη διεύθυνση της εφαρμογής και πρόσθεσε στο τέλος `recover.html`.
2. Συνδέσου με το παλιό email και τον κωδικό του TSERTOS CRM.
3. Έλεγξε ότι εμφανίζονται οι πελάτες και τα αυτοκίνητα.
4. Πάτησε **Μενού → Εξαγωγή backup** και αποθήκευσε το JSON στην εφαρμογή **Αρχεία**.
5. Μετά την επιτυχημένη ανάκτηση, διέγραψε το `recover.html` από το repository και κάνε νέο commit. Η τελική εφαρμογή δεν χρειάζεται σύνδεση στο Supabase.

## Εγκατάσταση στο iPhone

1. Άνοιξε στο **Safari** την κύρια διεύθυνση του GitHub Pages, χωρίς `recover.html`.
2. Πάτησε το κουμπί **Κοινοποίηση**.
3. Επίλεξε **Προσθήκη στην οθόνη Αφετηρίας** και μετά **Προσθήκη**.
4. Άνοιξε το εικονίδιο **TSERTOS CRM** από την αρχική οθόνη.
5. Πάτησε **Μενού → Εισαγωγή backup** και επίλεξε το JSON.
6. Κλείσε το Wi-Fi/τα δεδομένα και άνοιξε ξανά την εφαρμογή για να επιβεβαιώσεις ότι λειτουργεί offline.

## Σημαντικό για τα δεδομένα

- Οι εγγραφές δεν αποστέλλονται στο GitHub. Το GitHub φιλοξενεί μόνο τον κώδικα της εφαρμογής.
- Τα δεδομένα αποθηκεύονται στον χώρο του συγκεκριμένου web app στο iPhone.
- Αν διαγραφεί η εφαρμογή από την αρχική οθόνη, καθαριστούν τα δεδομένα του Safari ή αλλάξει η διεύθυνση GitHub Pages, μπορεί να χαθεί η τοπική βάση.
- Κάνε τακτικά **Εξαγωγή backup** και φύλαγε δεύτερο αντίγραφο στο Mac ή σε εξωτερικό δίσκο.
