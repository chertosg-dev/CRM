# Υποστήριξη iPad — V9.13.8

Η εφαρμογή διαθέτει πλέον ειδική διάταξη για iPad και προσαρμόζεται αυτόματα όταν η συσκευή αλλάζει από κατακόρυφη σε οριζόντια θέση.

## Εμφάνιση

- Σε κατακόρυφη θέση, η αρχική οθόνη εμφανίζει τέσσερις κάρτες ανά σειρά.
- Σε οριζόντια θέση, εμφανίζει έως επτά κάρτες ανά σειρά και επαναφέρει τη δίστηλη προβολή αναζήτησης και πελάτη.
- Τα προσωπικά στοιχεία και οι φόρμες αξιοποιούν δύο στήλες.
- Τα παράθυρα συμβολαίων και καλύψεων εμφανίζονται κεντραρισμένα, με περιθώριο γύρω τους και σωστή κύλιση αφής.

## Εγκατάσταση

1. Άνοιξε τη διεύθυνση της εφαρμογής στο Safari του iPad.
2. Πάτησε **Κοινοποίηση**.
3. Επίλεξε **Προσθήκη στην οθόνη Αφετηρίας**.
4. Άνοιξε την εφαρμογή από το νέο εικονίδιο.
5. Κάνε **Εισαγωγή backup** μόνο αν θέλεις να μεταφέρεις στο iPad τα δεδομένα που βρίσκονται στο iPhone.

Η βάση είναι τοπική ανά συσκευή. Η εγκατάσταση στο iPad δεν αντιγράφει αυτόματα τα δεδομένα του iPhone.
