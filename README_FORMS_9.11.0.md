# TSERTOS CRM V9.11.0 — Visual PDF Mapping

Η έκδοση αυτή προσθέτει οπτική αντιστοίχιση για PDF χωρίς διαδραστικά πεδία.

## Ροή
1. Προσθήκη PDF στη βιβλιοθήκη.
2. Αν δεν υπάρχουν AcroForm πεδία, ανοίγει οπτική αντιστοίχιση.
3. Επιλογή πεδίου CRM και πάτημα στο ακριβές σημείο του PDF.
4. Αποθήκευση της αντιστοίχισης.
5. Επιλογή πελάτη/συμβολαίου και Αυτόματη συμπλήρωση.
6. Προεπισκόπηση, χειροκίνητο όνομα και αποθήκευση/κοινοποίηση.

Το κείμενο στα οπτικά πεδία αποτυπώνεται ως εικόνα κειμένου ώστε να υποστηρίζει σωστά ελληνικούς χαρακτήρες χωρίς εξωτερικά font αρχεία.
