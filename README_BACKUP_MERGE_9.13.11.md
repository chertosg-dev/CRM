# Αμφίδρομη ενημέρωση iPhone–iPad — V9.13.11

Η εισαγωγή backup λειτουργεί πλέον πάνω σε βάση που περιέχει ήδη δεδομένα.

## Διαδικασία ενημέρωσης

1. Στη συσκευή με τις πιο πρόσφατες αλλαγές πάτησε **Εξαγωγή backup**.
2. Αποθήκευσε το αρχείο JSON στα Αρχεία ή στείλε το στην άλλη συσκευή με AirDrop.
3. Στην άλλη συσκευή πάτησε **Ενημέρωση από backup**.
4. Επίλεξε το JSON και επιβεβαίωσε τη συγχώνευση.

## Τι κάνει η συγχώνευση

- Ενημερώνει τις ήδη υπάρχουσες κοινές εγγραφές με τα στοιχεία του backup.
- Προσθέτει τις εγγραφές που λείπουν.
- Δεν διαγράφει εγγραφές που υπάρχουν μόνο στη συσκευή προορισμού.
- Περιλαμβάνει πελάτες, συμβόλαια και καλύψεις Ζωής, καλυπτόμενα μέλη, Αυτοκίνητα, Πυρός και Αποδείξεις.

Το αρχείο που εισάγεται θεωρείται νεότερο για τις κοινές εγγραφές. Μετά τη συγχώνευση μπορείς να βγάλεις νέο backup από την ενημερωμένη συσκευή και να το περάσεις ξανά στην άλλη.
