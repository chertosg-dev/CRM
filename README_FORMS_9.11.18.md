# TSERTOS CRM PWA V9.11.18

## Διόρθωση OCR άδειας κυκλοφορίας

- Αυστηρή αναγνώριση των κωδικών D.1, D.2, B, 4, E, P.5, P.3 και R μόνο όταν εμφανίζονται στην αρχή της αντίστοιχης γραμμής.
- Δεν γίνονται πλέον δεκτές άσχετες φράσεις της άδειας ως VIN, μάρκα, τύπος, κινητήρας ή χρώμα.
- VIN γίνεται δεκτό μόνο σε έγκυρη μορφή 17 χαρακτήρων.
- Καύσιμο και χρώμα περνούν από ελεγχόμενο λεξιλόγιο.
- Έλεγχος εγκυρότητας ημερομηνιών.
- Εφεδρική αναγνώριση κοινών μαρκών αυτοκινήτου.
- OCR σε sparse-text mode για καλύτερη ανάγνωση εντύπων/καρτών.

Η αντιστοίχιση των πεδίων της άδειας στο πρότυπο PDF εξακολουθεί να γίνεται μία φορά.
