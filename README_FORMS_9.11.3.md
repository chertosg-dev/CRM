# TSERTOS CRM V9.11.3 — iPhone PDF storage fix

- Τα PDF αποθηκεύονται ως raw bytes (ArrayBuffer) αντί για Blob στο IndexedDB, για αποφυγή iOS/Safari `NotFoundError: The object can not be found here.`
- Νέο κουμπί **↻ PDF** σε κάθε έντυπο: επανασύνδεση του αρχικού PDF χωρίς απώλεια οπτικών πεδίων/θέσεων/μεγεθών.
- Τα νέα έντυπα αποθηκεύονται εξαρχής με το νέο ασφαλέστερο format.
- Παλιά έντυπα μετατρέπονται αυτόματα όταν το αποθηκευμένο Blob παραμένει αναγνώσιμο.
- Αν το παλιό Blob έχει ήδη χαθεί από το iPhone, αρκεί μία επαναφόρτωση του ίδιου αρχικού PDF με **↻ PDF**.
