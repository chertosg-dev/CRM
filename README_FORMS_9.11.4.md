# TSERTOS CRM V9.11.4 — Μόνιμη αντιστοίχιση προτύπων

- Η αντιστοίχιση αποθηκεύεται μόνιμα μαζί με το πρότυπο PDF στη Βιβλιοθήκη Εντύπων.
- Για νέο πελάτη επιλέγεις το ήδη αποθηκευμένο έντυπο από τη βιβλιοθήκη· δεν χρειάζεται νέα μεταφόρτωση.
- Αν ανεβάσεις κατά λάθος ξανά το ίδιο ακριβώς PDF, γίνεται έλεγχος περιεχομένου (fingerprint) και η εφαρμογή προτείνει το ήδη αποθηκευμένο πρότυπο.
- Οι υπάρχουσες θέσεις, μεγέθη γραμματοσειράς και αντιστοιχίσεις δεν χάνονται.
- Τα παλαιότερα αποθηκευμένα πρότυπα αποκτούν fingerprint αυτόματα όταν είναι αναγνώσιμα.
