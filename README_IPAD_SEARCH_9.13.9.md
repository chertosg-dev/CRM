# Διόρθωση αναζήτησης iPad — V9.13.9

Στην έκδοση V9.13.8 η αναζήτηση φιλτράριζε τις εγγραφές, αλλά σε iPad κατακόρυφης διάταξης η λίστα αποτελεσμάτων παρέμενε κρυμμένη από τον κανόνα εμφάνισης του κινητού.

Η V9.13.9:

- εμφανίζει κανονικά τη λίστα αποτελεσμάτων στο iPad,
- χρησιμοποιεί δύο στήλες για τις καρτέλες πελατών,
- εμφανίζει την καρτέλα του επιλεγμένου πελάτη ακριβώς από κάτω,
- μετακινεί αυτόματα την οθόνη στα στοιχεία του πελάτη μετά την επιλογή,
- διατηρεί την ξεχωριστή mobile αναζήτηση όταν το iPad χρησιμοποιείται σε Split View με πολύ στενό παράθυρο.
