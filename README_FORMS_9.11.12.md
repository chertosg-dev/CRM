# TSERTOS CRM V9.11.12 — Popup Forms Picker + Supplemental Document Fields

## Τι αλλάζει

- Η μόνιμη μικρή στήλη της βιβλιοθήκης κρύβεται.
- Η επιλογή εντύπου γίνεται πλέον από μεγάλο pop-up: πρώτα **Κατηγορία**, μετά **Έντυπο**.
- Το επιλεγμένο πρότυπο εμφανίζεται καθαρά στην κύρια οθόνη με κουμπιά για Πεδία, Στοιχεία και ανανέωση PDF.
- Προστέθηκε προαιρετικό **Συμπληρωματικό PDF** για στοιχεία που δεν υπάρχουν στο CRM.
- Στην αντιστοίχιση μπορείς να δημιουργείς δικά σου πεδία «από συμπληρωματικό έγγραφο» και να τα τοποθετείς στο τελικό έντυπο όπως τα πεδία CRM.
- Κατά τη χρήση, το συμπληρωματικό PDF αναλύεται για text/form values με βάση την ετικέτα που όρισες. Οι τιμές εμφανίζονται σε επεξεργάσιμα πεδία πριν την αυτόματη συμπλήρωση.
- Αν ένα PDF είναι σαρωμένο/εικόνα και δεν περιέχει αναγνώσιμο κείμενο, οι τιμές μπορούν να συμπληρωθούν χειροκίνητα στα ίδια πεδία πριν δημιουργηθεί το τελικό PDF.

## Ροή

1. Επιλογή εντύπου → Κατηγορία → Πρότυπο.
2. Επιλογή πελάτη και, αν χρειάζεται, συμβολαίου/προσώπου.
3. Προαιρετικά ανέβασμα συμπληρωματικού PDF.
4. Έλεγχος/διόρθωση των τιμών που βρέθηκαν από το συμπληρωματικό PDF.
5. Αυτόματη συμπλήρωση και αποθήκευση με όνομα που δίνει ο χρήστης.
