# TSERTOS Insurance CRM — V9.10.0 Forms Library

## Νέα ενότητα «Έντυπα»

Η έκδοση 9.10.0 προσθέτει βιβλιοθήκη PDF μέσα στο υπάρχον CRM, ώστε η συμπλήρωση να χρησιμοποιεί απευθείας τα ίδια τοπικά δεδομένα πελατών.

### Ροή
1. Πατάς **Έντυπα**.
2. Πατάς **+ PDF** και προσθέτεις ένα έντυπο στη βιβλιοθήκη.
3. Για PDF που έχουν διαδραστικά πεδία φόρμας, η εφαρμογή εντοπίζει τα πεδία.
4. Στην **Αντιστοίχιση πεδίων** συνδέεις μία φορά κάθε πεδίο PDF με στοιχείο του CRM (ονοματεπώνυμο, ΑΦΜ, ΑΔΤ, διεύθυνση, συμβόλαιο κ.λπ.). Γίνεται και αρχική αυτόματη πρόταση αντιστοίχισης.
5. Επιλέγεις πελάτη, συμβόλαιο και — όπου υπάρχει — καλυπτόμενο μέλος.
6. Πατάς **Αυτόματη συμπλήρωση**.
7. Εμφανίζεται προεπισκόπηση του νέου PDF.
8. Πατάς **Αποθήκευση νέου PDF**.
9. Το όνομα του νέου αρχείου είναι **υποχρεωτικό και το γράφεις εσύ**. Δεν δημιουργείται αυτόματα.
10. Στο iPhone ανοίγει η κοινή χρήση, από όπου μπορείς να επιλέξεις **Αποθήκευση στα Αρχεία**.

### Τι παραμένει ανέπαφο
- Το πρωτότυπο PDF στη βιβλιοθήκη δεν τροποποιείται.
- Τα δεδομένα πελατών του CRM δεν αλλάζουν όταν δημιουργείται PDF.
- Κάθε συμπλήρωση δημιουργεί νέο αρχείο.

### Αποθήκευση βιβλιοθήκης
Τα PDF της βιβλιοθήκης και οι αντιστοιχίσεις τους αποθηκεύονται τοπικά στο IndexedDB της εφαρμογής στο iPhone.

### Περιορισμός της πρώτης έκδοσης
Η αυτόματη συμπλήρωση V9.10.0 λειτουργεί σε PDF που περιέχουν πραγματικά διαδραστικά πεδία φόρμας (AcroForm). Ένα επίπεδο/σκαναρισμένο PDF μπορεί να αποθηκευτεί στη βιβλιοθήκη, αλλά χρειάζεται το επόμενο στάδιο — οπτική τοποθέτηση πεδίων πάνω στη σελίδα — για να συμπληρώνεται αυτόματα.

### PDF engine
Για την επεξεργασία διαδραστικών PDF χρησιμοποιείται `pdf-lib 1.17.1`. Η εφαρμογή προσπαθεί να το φορτώσει από jsDelivr και, αν αποτύχει, από unpkg.
