# Καρτέλα πελάτη — V9.13.3

- Η επάνω σειρά με τα τρία badges αποτελεί πλέον τη μοναδική πλοήγηση για Ζωή, Αυτοκίνητο και Πυρός.
- Αφαιρέθηκε η δεύτερη επαναλαμβανόμενη σειρά καρτελών κλάδων.
- Η επιλογή πελάτη με όνομα, επωνυμία ή ΑΦΜ ανοίγει αρχικά τα προσωπικά στοιχεία.
- Κάθε badge ανοίγει τον αντίστοιχο κλάδο μόνο όταν υπάρχουν συμβόλαια.
- Τα badges με μηδενικό πλήθος είναι ανενεργά.
- Νέο πάτημα στο ενεργό badge ή πάτημα στην επάνω ταυτότητα του πελάτη επιστρέφει στα προσωπικά στοιχεία.
